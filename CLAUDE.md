# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

veda64 is an ARM64 (AArch64) instruction encoder, decoder, and disassembler library with inline hooking support for Windows. The library is **100% AI-generated** from official ARM XML ISA specifications and covers 2,292 instructions across 4,623 encoding variants. All instruction encodings use **little-endian** byte order.

## Architecture

### Code Generation Pipeline

**All `.cpp` and `.hpp` files in this repository are generated by `parse_arm64_xml.py`** from ARM XML specifications in `arm64/ISA_A64_xml_A_profile-2025-*/`. **Do not manually edit any C++ source or header file** — modify `parse_arm64_xml.py` instead and regenerate. The only file that should be directly modified is `parse_arm64_xml.py` (and build/config files like `CMakeLists.txt`). Generated directories:
- `include/format/` and `lib/format/` — format-specific encoding structures and decoders
- `include/` (top-level headers) and `lib/` (top-level sources) — also generated

### Published Files

The following files are intended for public distribution (the `arm64/` XML specs are **not** published):

- `include/` and `lib/` — generated library source
- `test/` — generated test suite
- `tools/` — disassembler CLI tool
- `CMakeLists.txt` — build configuration
- `README.md` — user documentation

The following files are **not** published: `parse_arm64_xml.py`, `CLAUDE.md`, `arm64/`.

### Key Components

**Main Header** (`include/veda64.hpp`):
- `Mnemonic` enum: 1,031 ARM64 instruction mnemonics
- `OperandType` enum: Register, Immediate, Memory variants, etc.
- `Operand` class: Decoded operand with type, value, and memory fields
- `Instruction` class: Decoded instruction with mnemonic, operands, raw value
- `decode()`: Unified decoder function that dispatches to the correct format group
- `from_bytes()`/`to_bytes()`: Little-endian byte-order conversion helpers

**Hook API** (`include/hook.hpp`, `lib/hook.cpp`) — Windows only:
- Inline hooking with instruction relocation via NT syscalls (no Win32 API dependency)
- Thread-safe hook installation via NtSuspendProcess/NtResumeProcess
- Helper macros: `VEDA64_DECLARE_ORIGINAL`, `VEDA64_INSTALL_HOOK`, `VEDA64_CALL_ORIGINAL`

### Format-Based Disassembler Architecture

The disassembler is organized by **top-level encoding group** from `encodingindex.xml`, not by instruction class. Each group has one header and one implementation file (`include/format/<group>.hpp`, `lib/format/<group>.cpp`). Group names match the `groupname` attributes in `encodingindex.xml`:

- **`reserved`** (`Reserved`) — Unallocated encodings
- **`sme`** (`Sme`) — Scalable Matrix Extension
- **`sve`** (`Sve`) — Scalable Vector Extension
- **`dpimm`** (`Dpimm`) — Data Processing - Immediate (PC-relative, add/sub immediate, logical immediate, move wide, bitfield, extract)
- **`control`** (`Control`) — Branches, Exception Generating and System instructions
- **`dpreg`** (`Dpreg`) — Data Processing - Register (1/2/3-source, logical shifted, add/sub shifted/extended, carry, conditional compare/select)
- **`ldst`** (`Ldst`) — Loads and Stores (exclusive, pair, immediate, register offset, unsigned immediate, literal, atomic)
- **`simd_dp`** (`SimdDp`) — Data Processing - Scalar Floating-Point and Advanced SIMD

**Dispatch:** `format.hpp` provides `decode_format(uint32_t)` which dispatches to the correct group decoder based on `op0` (bit 31) and `op1` (bits [28:25]). Each group's decode function then matches specific instruction encodings.

### Encoding/Decoding Conventions

Each instruction format requires:

1. **Encoding struct**: A bitfield struct mapping directly to the ARM64 instruction format, with `static_assert(sizeof(T) == 4)`. The struct name must follow the format's psname (e.g., `AddSubImmediate`, `UnconditionalBranchImm`, `PCRelAddr`).

2. **Union with raw access**: The main encoding structure must use a union containing both the bitfield struct and a `uint32_t raw` member, allowing direct access to the raw 32-bit instruction value.

3. **Dual-purpose structs**: The same structures must be used for **both** encoding and decoding — encode via static `encode()` method, decode via static `decode()` method that returns `std::optional<T>`.

4. **Match function**: Each format has a `matches(uint32_t insn)` method using fixed-bit masks to identify instructions belonging to that format.

5. **Operand support**: Each format's `to_instruction()` method must correctly populate all operands with proper `OperandType` values (Register, Immediate, Memory variants, Condition, Shift, etc.) for accurate disassembly.

6. **Switch/case optimization**: When multiple instructions within a format share the same mask (i.e., differ only in specific field values), decoding must be optimized as a `switch`/`case` on the distinguishing field rather than sequential if/else chains.

```cpp
// Format struct example (include/format/addsub_imm.hpp)
struct Encoding {
    uint32_t Rd : 5;
    uint32_t Rn : 5;
    uint32_t imm12 : 12;
    uint32_t sh : 1;
    uint32_t _unnamed_0 : 6;  // fixed: 0b100010
    uint32_t S : 1;
    uint32_t op : 1;
    uint32_t sf : 1;
};
static_assert(sizeof(Encoding) == 4, "Encoding must be 32 bits");

// Per-format namespace with matches + encode + decode
namespace AddsubImm {
    inline bool matches(uint32_t insn) {
        return (insn & 0xFF800000U) == 0x11000000U;
    }
    std::optional<Instruction> decode(uint32_t insn);
}
```

### Test Structure

Tests are in `test/test_*.cpp` (auto-discovered by CMake via glob). `test_reference.cpp` validates decode output against known disassembly. `test_aliases.cpp` tests 58+ ARM architectural aliases (MOV/ORR, CMP/SUBS, etc.). Tests are plain executables returning 0 on success. **Every new instruction format, encoding, and operand type must have corresponding tests.**

## Platform Notes

- **Windows**: Links `ntdll.lib` for hooking support (NT syscalls)
- **Linux/Other**: Hooking not available, encode/decode works normally
- **C++17** required (CMake 3.14+)
- **VEDA64_NO_STRINGS**: Compile definition to remove all string/formatting functions
